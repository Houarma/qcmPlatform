Le projet

Qu'est-ce que
QCM Platform ?

Une application full-stack où l'IA génère des questions d'évaluation à partir d'objectifs pédagogiques, et analyse les performances via des algorithmes ML.

🎯 Problématique

La création de QCM est chronophage. Les enseignants manquent d'outils d'analyse des résultats étudiants.

💡 Notre réponse

LLM + ML + Cloud = une plateforme complète, du QCM à l'analyse en passant par la notification automatique.

Orchestration

Flux applicatifs
FLUX 1 — Création évaluation
1
POST /api/evaluations → FirebaseTokenFilter
2
SecurityConfig : hasRole("ENSEIGNANT") → OK
3
RestTemplate → FastAPI /generate → Groq LLM
4
Pydantic valide · JSON → QuestionGeneree Java
5
JPA persist Evaluation + Questions + Options
FLUX 2 — Soumission test
1
POST /api/resultats · hasRole("ETUDIANT")
2
Vérifie statut == PUBLIEE (sinon 403)
3
Compare réponses → bonneReponse par question
4
score = (correctes / total) × 100 → persiste
FLUX 3 — Analyse ML
1
GET /api/analyses/{id} · hasRole("ENSEIGNANT")
2
ResultatRepository → tous les résultats DB
3
Transforme en JSON snake_case → FastAPI /analyse
4
K-Means · IRT · lacunes calculés en Python
5
Jackson désérialise camelCase → AnalyseResponse
@Async — Email non bloquant

Lors de la publication, l'email Brevo est envoyé dans un thread séparé. La réponse HTTP retourne immédiatement sans attendre l'envoi.
